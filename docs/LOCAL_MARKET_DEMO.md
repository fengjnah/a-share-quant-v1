## 功能

- TASK-M2 在同一应用侧栏增加“交易分析”，直接入口 `/?view=analysis`。本地分析与显式采集分开；使用当前临时演示库，可指定股票、分析日期、历史起始日及可选账户权益，支持本地同源池最多20只的研究评分。侧栏“打开已有临时演示区”复用相同受限路径校验，仅切换当前会话，不移动或删除库；刷新仍按进程配置打开。
- 仓库没有既有正式指标/策略实现，`m2-research-v1` 仅为研究 Demo：MA5/10/20/60；TR 为振幅与相对前收缺口最大值，ATR14 以14个有效TR均值为种子（需15条行情），随后 Wilder 平滑。参考 [TA-Lib v0.6.4 ATR源码](https://github.com/TA-Lib/ta-lib/blob/v0.6.4/src/ta_func/ta_ATR.c) 与 [BSD许可](https://github.com/TA-Lib/ta-lib/blob/v0.6.4/LICENSE)，只核对数学公式，未增加依赖或复制源码。预期单独 ATR 测试路径未取得，未声称运行上游测试，本项目用手算与未来隔离反例验证。
- 研究条件：`C>MA5>MA10>MA20>MA60` 为日线趋势；量比以前5条均量为基准，≥1.5放量、≤0.7缩量、≥10异常待验；突破需收盘严格超过前20条最高价；回调需收盘低于前收、最低≤MA20≤收盘且缩量；阳线实体严格跨过前一日MA5/10/20为穿三线。评分分别40/25/20/15，未知不补0；完整公式、计算明细与版本在页面公开，未验证预测能力。
- 周样本只取分析日所在周之前的日历周，比较周观察值MA5/MA20；交易日覆盖未认证，不作为正式周线过滤通过。当前没有已验证指数/全市场覆盖、历史ST/市值/交易状态，因此市场显示“数据不足”、正式候选为0，不用单股推断市场。未验收CFFEX不是依赖。
- 结构止损为前10条最低价，ATR止损为所属日收盘减2×ATR14；两者均在零与参考收盘之间时取较高者，否则为空。权益为空时不填默认资金或股数；预算=权益×1%，理论股数向下取整并受现金上限约束，未按交易单位取整、未计费用滑点，不是订单。
- 指标按行情截止日及 `as_of` 过滤，派生可用时间不早于实际计算及依赖入库时间，不回填成当日盘中已知信号。停牌、涨跌停、T+1、公司行为及下一可交易会话仍需另验，不代表实盘准入。
- M1 在同一应用中提供“查询本地已有数据”和“采集真实行情”两个独立按钮。前者不联网、不创建采集批次；后者仍使用现有采集器，不自动切换源或覆盖重复版本。
- 查询按股票、起止日期、不复权及具体适配器来源过滤，通过现有可见版本接口读取并校验。页面共用同一份数据绘制收盘价走势、成交量（股）和行情明细。少于两条记录时明确不绘制价格走势，不补点。
- 采集成功需逐字段比较 SQLite 读回值；网络错误、空响应、输入错误、SQLite 错误、读回不一致分别提示。SDK 未暴露的 HTTP 状态仍为未知。交易日覆盖完整性没有因此认证。
- 使用现有 `AkshareDailyClient`（东方财富主源）与 `TxDailyClient`（腾讯备用候选，TASK-008A）通过同一 `DailyHistoryIngestor` 与 `SQLiteMarketDataRepository`。
- 默认表单预填 `600000`、`2026-10-14` 至 `2026-10-15`、不复权；这只是查询参数，不代表已查询数据。
- 只有用户点击“采集真实行情”才会发起请求。
- 展示实际采集状态、返回/入库行数、来源、观察时间、证据摘要、错误信息，以及从隔离 SQLite 数据库重新查询的行情表。
- 数据源默认仍为东方财富；腾讯选项为备用候选，页面明确标注“尚未通过生产适用性验收”。
- 不读取 `QUANT_DB_PATH`，不调用生产数据库路径，不会自动初始化 `local.sqlite3`。
- 每个 Streamlit 会话使用操作系统临时目录下独立的 `demo.sqlite3`；页面显示实际路径。

## 操作方法

1. 保持默认股票代码和日期，或输入支持的沪深 A 股代码。数据源默认“东方财富（主源）”；腾讯只能显式手动选择，失败不会自动切换。
2. 已有数据优先点击“查询本地已有数据”，不发网络请求；只有点击“采集真实行情”才重新请求供应商。
3. 成功时，页面显示实际返回行数、入库行数、来源和 SQLite 读回数据。
4. 失败时，页面显示错误状态，不会用示例行情填充表格。若出现网络/TLS 错误，请保留错误信息，不要关闭 TLS 验证。
5. “新建隔离演示区”切换到新会话临时库，不删除原库或证据；临时文件由操作系统清理机制处理。
