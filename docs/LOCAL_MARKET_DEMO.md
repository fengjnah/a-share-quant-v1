# 本地行情展示页（最小版）

## 项目进度入口（已随 PR #21 合并）

同一个 Demo 的侧栏“工作区”可选择“项目进度”，或打开现有本地服务 `http://127.0.0.1:8502/?view=progress` 直接进入（其他端口以启动日志为准）。该页在导入行情/SQLite 模块之前分流，读取 [TASK_METRICS.json](TASK_METRICS.json)，不创建数据库、不请求行情，也不修改任务状态；行情初始化或接口失败不影响进度页。东方财富仍是行情工作台的默认源。

页面顶部展示近期交付证据（M0/M1/M2等）和正式加权验收进度，两者不会互相替代；任务总览可按状态、阶段和编号/名称筛选。筛选不改变完成率。任务详情可展开来源、摘要、绑定提交与哈希；旧事件和证据保留，展示不后台同步GitHub或改写任务状态。

独立启动同一进度渲染器：

```powershell
# 在含当前版本代码的干净开发目录及项目虚拟环境执行
$env:PYTHONPATH = Join-Path (Get-Location) 'src'
.\.venv\Scripts\python.exe -m streamlit run src/ai_trade/project_progress/app.py --server.address 127.0.0.1
.\.venv\Scripts\python.exe -m ai_trade.project_progress --check-docs
```

采用已有 `.[demo,test]` 安装方式；新增直接轻量依赖 jsonschema 用于真正的 JSON Schema 验证。本轮既有环境已安装，未升级或重装。正式口径/反馈与候选文件操作见 [任务看板](TASK_BOARD.md)，十阶段见 [路线图](ROADMAP_V1_3.md)。验收证据、PR 和生产准入分列；首版权重不是生产就绪率，历史真实样本不能证明当前源健康。

健康检查采用独立、默认离线的 [TASK-015 入口](SOURCE_HEALTH_CHECKS.md)，不会在页面启动或 rerun 时自动执行。可只读展示其序列化报告；配置成功不代表真实行情健康。本轮没有改变 Demo 默认数据源、请求逻辑或生产数据库配置。

## 功能

- TASK-M2 在同一应用侧栏增加“交易分析”，直接入口 `/?view=analysis`。本地分析与显式采集分开；使用当前临时演示库，可指定股票、分析日期、历史起始日及可选账户权益，支持本地同源池最多20只的研究评分。侧栏“打开已有临时演示区”复用相同受限路径校验，仅切换当前会话，不移动或删除库；刷新仍按进程配置打开。
- 仓库没有既有正式指标/策略实现，`m2-research-v1` 仅为研究 Demo：MA5/10/20/60；TR 为振幅与相对前收缺口最大值，ATR14 以14个有效TR均值为种子（需15条行情），随后 Wilder 平滑。参考 [TA-Lib v0.6.4 ATR源码](https://github.com/TA-Lib/ta-lib/blob/v0.6.4/src/ta_func/ta_ATR.c) 与 [BSD许可](https://github.com/TA-Lib/ta-lib/blob/v0.6.4/LICENSE)，只核对数学公式，未增加依赖或复制源码。预期单独 ATR 测试路径未取得，未声称运行上游测试，本项目用手算与未来隔离反例验证。
- 研究条件：`C>MA5>MA10>MA20>MA60` 为日线趋势；量比以前5条均量为基准，≥1.5放量、≤0.7缩量、≥10异常待验；突破需收盘严格超过前20条最高价；回调需收盘低于前收、最低≤MA20≤收盘且缩量；阳线实体严格跨过前一日MA5/10/20为穿三线。评分分别40/25/20/15，未知不补0；完整公式、计算明细与版本在页面公开，未验证预测能力。
- 周样本只取分析日所在周之前的日历周，比较周观察值MA5/MA20；交易日覆盖未认证，不作为正式周线过滤通过。当前没有已验证指数/全市场覆盖、历史ST/市值/交易状态，因此市场显示“数据不足”、正式候选为0，不用单股推断市场。未验收CFFEX不是依赖。
- 结构止损为前10条最低价，ATR止损为所属日收盘减2×ATR14；两者均在零与参考收盘之间时取较高者，否则为空。权益为空时不填默认资金或股数；预算=权益×1%，理论股数向下取整并受现金上限约束，未按交易单位取整、未计费用滑点，不是订单。
- 指标按行情截止日及 `as_of` 过滤，派生可用时间不早于实际计算及依赖入库时间，不回填成当日盘中已知信号。停牌、涨跌停、T+1、公司行为及下一可交易会话仍需另验，不代表实盘准入。
- M1 在同一应用中提供“查询本地已有数据”和“采集真实行情”两个独立按钮。前者不联网、不创建采集批次；后者仍使用现有采集器，不自动切换源或覆盖重复版本。
- 查询按股票、起止日期、不复权及具体适配器来源过滤，通过现有可见版本接口读取并校验。页面共用同一份数据绘制收盘价走势、成交量（股）和行情明细。少于两条记录时明确不绘制价格走势，不补点。
- 采集成功需逐字段比较 SQLite 读回值；网络错误、空响应、输入错误、SQLite 错误、读回不一致分别提示。SDK 未暴露的 HTTP 状态仍为未知。交易日覆盖完整性没有因此认证。
- 使用现有 `AkshareDailyClient`（东方财富主源）与 `TxDailyClient`（腾讯备用候选，TASK-008A）通过同一 `DailyHistoryIngestor` 与 `SQLiteMarketDataRepository`。
- 默认表单预填 `600000`、`2026-10-14` 至 `2026-10-15`、不复权；这只是查询参数，不代表已查询数据。
- 只有用户点击“采集真实行情”才会发起请求。
- 展示实际采集状态、返回/入库行数、来源、观察时间、证据摘要、错误信息，以及从隔离 SQLite 数据库重新查询的行情表。
- 数据源默认仍为东方财富；腾讯选项为备用候选，页面明确标注“尚未通过生产适用性验收”。
- 不读取 `QUANT_DB_PATH`，不调用生产数据库路径，不会自动初始化 `local.sqlite3`。
- 每个 Streamlit 会话使用操作系统临时目录下独立的 `demo.sqlite3`；页面显示实际路径。

## Windows PowerShell 启动步骤

在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[akshare,demo]"

# 只对当前 PowerShell 会话及其启动的 Streamlit 进程生效。
# 仅在网络策略允许且明确选择东方财富直连时使用；配置本身不保证请求成功。
$env:NO_PROXY = "push2his.eastmoney.com"

.\.venv\Scripts\python.exe -m streamlit run src/ai_trade/demo_app.py
```

浏览器打开 Streamlit 启动日志中显示的本地地址（通常为 `http://localhost:8501`）。

## 操作方法

1. 保持默认股票代码和日期，或输入支持的沪深 A 股代码。数据源默认“东方财富（主源）”；腾讯只能显式手动选择，失败不会自动切换。
2. 已有数据优先点击“查询本地已有数据”，不发网络请求；只有点击“采集真实行情”才重新请求供应商。
3. 成功时，页面显示实际返回行数、入库行数、来源和 SQLite 读回数据。
4. 失败时，页面显示错误状态，不会用示例行情填充表格。若出现网络/TLS 错误，请保留错误信息，不要关闭 TLS 验证。
5. “新建隔离演示区”切换到新会话临时库，不删除原库或证据；临时文件由操作系统清理机制处理。

### 刷新后复用已有的真实演示数据

启动前可设置当前进程的 `AI_TRADE_DEMO_ROOT` 为之前页面显示的演示目录。只允许系统临时目录下已存在的 `a-share-quant-demo-*`，且其中已有普通 `demo.sqlite3` 文件；越界、链接越界或缺文件会拒绝。该配置不读取 `QUANT_DB_PATH`，不创建配置路径下的数据库。未设置时仍按浏览器会话隔离，新浏览器会话可能得到空库。

```powershell
# 将下面的占位目录替换为本机已有演示区；不存在时不要自行创建数据库来绕过检查。
$env:AI_TRADE_DEMO_ROOT = Join-Path $env:TEMP 'a-share-quant-demo-<已有目录后缀>'
$env:PYTHONPATH = Join-Path (Get-Location) 'src'
.\.venv\Scripts\python.exe -m streamlit run src/ai_trade/demo_app.py --server.address 127.0.0.1 --server.port 8502
```

页面“新建隔离演示区”只影响当前会话；指定了上述变量时，刷新会重新打开该变量指定的旧库。真实行情响应、SQLite 文件和机器专属目录不提交仓库。

## 安全与验收边界

- 此页面是本地开发演示，不是生产服务，不提供认证或多用户访问控制。
- 不创建、不读取生产数据库；临时数据在 Streamlit 会话中隔离。
- 不把数据库、响应快照、证据目录、日志或密钥提交到 Git。
- 成功展示仅证明该次请求及本次临时库读回成功，不证明完整历史覆盖、全部证券、持续可用性或策略盈利能力。
- 如果代理配置不允许直连该域名，请遵循组织网络策略；不要关闭 TLS 证书验证或擅自添加自动直连回退。
- 页面代理字段仅表示 Requests 配置推断，不证明实际 socket 路由。腾讯 SDK 会访问 `web.ifzq.gtimg.cn` 探测起始日、再访问 `proxy.finance.qq.com` 按年获取数据；一次点击/SDK 调用可能包含多次 HTTP GET，且起始日探测没有传入 timeout。Demo 不修改这些域名的系统代理。
- 腾讯 SDK 会去重，并在 `day` 缺失时选择 `hfqday/qfqday`；仅凭 SDK DataFrame 无法核验原始响应所选口径或去重前冲突。当前请求明确使用 `adjust=""`，但原始口径证据仍是生产使用阻断项，不能把该候选用于已验收的严格历史研究。
- TASK-009当时只复用TASK-008历史2行，见[历史集成报告](IMPLEMENTATION_TASK_009.md)；后续M0/M1与M2已有内置浏览器真实样本验收（2行/187行）。此处区分历史任务与后续交付，不将离线夹具、一次Demo成功或代码合并等同生产/长期覆盖验收。最新范围和证据见[项目状态](PROJECT_STATUS.md)。
