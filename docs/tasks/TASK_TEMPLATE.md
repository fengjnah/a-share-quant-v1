# TASK 模板

复制本模板创建一个具体任务；所有 `<填写>` 项在实现前替换。“未指定/自动/任选/候选列表”不能作为执行模型；不支持推理参数时须写明依据。未来计划中的审查 TASK 可待指派，但不得在模型/档位未填时执行。

## 1. 身份、目标与基线

| 字段 | 必填值 |
| --- | --- |
| TASK ID / 标题 | `<填写独立编号与标题>` |
| 类型 | `<填写 implementation / review / acceptance 等唯一类型>` |
| 目标与非目标 | `<填写可验证结果、明确不做的工作>` |
| 前置依赖 | `<填写 TASK/PR、状态、base/head SHA；无依赖也写无>` |
| 仓库 / 实际基线 SHA | `<填写完整仓库与已确认提交>` |
| 当前分支 / 工作区修改 | `<填写实际状态与保护方法，不得覆盖既有修改>` |

## 2. 唯一执行配置

| 字段 | 必填值 |
| --- | --- |
| 提供方 / 宿主 | `<填写，不把宿主名称当模型 ID>` |
| **唯一执行模型 ID/版本** | `<只填写一个具体值>` |
| **固定推理强度** | `<填写该型号支持的一个档位，或“不支持”及依据>` |
| 实际核验来源 / 时间 | `<运行元数据/界面/用户确认；不是仅计划配置>` |
| L/H 等级 / 风险理由 | `<填写；涉及强制 H 风险不能分配 L>` |
| 成本/可用性核验 | `<来源日期、上下文/工具兼容性；未知费用明确写未知>` |
| 预算 / 重试上限 | `<填写上限与计数方法；同一验收问题最多两次诊断性修复，核心失败立即升级>` |

本 TASK 内不切换模型/推理档位，不调用其他模型完成实现或正式审查，不以换角色、子代理、API fallback 或换线程规避。需要改变时保留现场并另立升级 TASK。

## 3. 必读与开始报告（实现前）

执行模型必须先**实际读取**：

- [根目录 AGENTS.md](../../AGENTS.md)。
- [模型路由制度](../MODEL_ROUTING_POLICY.md)。
- [项目状态](../PROJECT_STATUS.md)、[架构决策](../DECISIONS.md)。
- `<列出本任务相关模块的数据/接口契约、实施报告、代码和测试路径；检查适用的子目录/override 规则>`。

在开始报告中填写以下证据，不能只写“已了解”：

```text
TASK ID：
已实际阅读：路径 + 版本/基线 SHA
适用规则：G01—G12 中具体编号 + 对本任务的要求
规则冲突/缺失或 override：无 / 具体路径与处理
实际模型 / 固定推理强度 / 核验来源：
基线、依赖 PR 状态、当前分支、未提交修改及保护措施：
允许范围、验收命令、批次/独立审查计划：
```

## 4. 修改边界与约束

- 允许修改的文件/行为：`<精确列出路径或边界>`。
- 禁止修改的文件/行为：`<包含 main、生产数据库及任务外模块>`。
- 数据/接口不变量：`<写明时间、身份、版本、单位、缺失/错误语义等；不适用说明理由>`。
- 数据来源与网络：`<允许来源、显式启用方式、请求/超时/重试上限；默认离线不得联网>`。
- 安全：不关闭 TLS，不伪造真实数据，不提交密钥/代理凭据/SQLite/未经审查响应，不自动合并/部署或接账户。
- 本次不变更已确认契约；冲突时立即停止扩大修改、记录证据并另立 H TASK，不能自行降低约束。

## 6. 分支、交付及报告

- 目标分支：`<独立分支>`；PR base：`<确认过的分支及 SHA>`。已存在同名分支先检查，不强推覆盖；依赖未合并则明确堆叠关系。
- 交付文件：`<列表及用途>`；实施记录位置：`<任务单/实施报告/PR>`。
- 最终报告：模型/档位与核验来源、实际文件差异、执行命令及输出、风险/未验证项、未完成内容、提交 SHA、PR 链接。未执行的项不能写通过。

- 合并与部署：只提交 PR 供人工处理；本 TASK 不自动合并或部署。

## 7. 批次、后续与升级

| 字段 | 必填值 |
| --- | --- |
| 审查批次 ID / 已累计未审 L TASK | `<填写 TASK/PR/SHA 列表；H 写独立审查不等待批次>` |
| 独立 H 审查 TASK / 状态 | `<编号/待指派计划；执行前必须填自己的唯一 H 模型与档位>` |
| 审查边界 / 门禁 | `<冻结 SHA、必须覆盖的断言、审查前不能宣称的阶段结果；高风险合并前必须通过独立审查>` |
| 后续任务 | `<明确目标与依赖，不在当前 TASK 偷做>` |
| 升级条件 | 核心测试失败/契约或时间冲突/迁移风险立即阻断；两次诊断性修复仍失败或达到预算则停止并建立独立 H TASK |
| 阻断报告位置 | `<含基线、命令/输出、影响、尝试、现场与最小方案>` |

审查类型 TASK 只报告问题和结论，不修改被审实现；修复另立 TASK，再对新 SHA 复核。恢复执行时先核对模型、现场和已有测试日志，保留进度，不以新编号抹去失败记录。
