# A股量化交易系统 V1.3

面向 A 股日频、周频研究的量化分析系统，目标是建立可追溯的数据历史，支持市场状态判断、选股、择时、风险控制与公平对照回测，并在本地生成每日精选 3–5 只股票和指定标的分析的静态日报，供手机浏览。

**当前已实现最小 SQLite 数据层和 TASK-003 历史日线适配器。** 数据层提供初始化/迁移、校验、原子写入、追加版本和按时点读取；采集子集只支持 AKShare 单接口的沪深 A 股、不复权、过去日期日线，已有离线测试，真实接口手工测试尚未执行。完整证券主数据、日历、复权计算、完整 DataAccess/快照服务、策略、回测、日报、发布和 CI 仍未实现，系统未部署、不连接账户或自动下单，也不保证收益。详见 [TASK-002](docs/IMPLEMENTATION_TASK_002.md) 和 [TASK-003 实施记录](docs/IMPLEMENTATION_TASK_003.md)。

## 功能范围与关键约束

| 规划能力 | 范围与约束 | 当前状态 |
| --- | --- | --- |
| 数据底座 | 公开行情、历史证券状态、交易日历、公司行为、财务公告和历史成分；原始载荷归档与版本化 | 已有最小日线仓储及单接口历史采集、SDK 快照证据；真实源验收和其余数据集待完成 |
| 市场与板块 | 全 A 等权等市场宽度、连续普跌恢复、历史行业/概念强弱 | 待实现，部分规则待确认 |
| 选股与择时 | 非 ST、可交易、历史可得总市值不少于 100 亿元的保守股票池；成长、龙头、热度评分及日/周信号 | 待实现，业务定义待确认 |
| 风控与回测 | 仓位、集中度、止损；停牌、涨跌停、复权、公司行为、费用与滑点；允许空仓与持续持仓对照 | 待实现 |
| 外围证据 | 全球风险代理、公开期货会员排名及证据分级 | 待实现，来源与代理口径待确认 |
| 日报与访问 | 本地构建 HTML/JSON 与 manifest；人工审阅后由 AWS 静态托管 | 待实现，访问方案待确认 |

所有研究与回测读取必须显式指定 `as_of`。数据保留 `source`、`event_time`、`available_at`、`ingested_at`；严格模式同时约束可得时间与入库时间，拒绝缺失可得时间的数据。修订数据不得覆盖旧版本，当前成分不得回填历史。研究模式放宽时须明确标注非审计。

完整日线生成的信号最早在下一可交易会话执行；周线只在本周最后一个交易日收盘且数据可用后用于严格信号，最早在下一交易周执行。模拟成交采用原始价格及可交易性规则，不能直接以收盘价假定成交。公开会员数据或代理不得命名为无法验证的“机构净持仓”。详细定义以数据、接口契约为准。

## 总体架构（规划）

```text
公开数据源（AKShare 仅为候选适配器）
  → 采集适配器 / 日历 / 证券主数据 / 公司行为
  → 原始载荷归档 + 标准化验证 + 数据血缘
  → DataAccess（默认 SQLite；未来预留 Parquet/DuckDB）
  → 特征 / 市场状态 / 板块分析 / 全球风险
  → 股票池过滤 → 选股评分 → 入场择时 → 风险约束
  → 回测编排 / 执行模拟 / 组合记账 / 审计报告
  → 本地日报构建（HTML / JSON / manifest）
  → 本地人工审阅与校验 → 静态同步 → AWS Nginx → 手机浏览器
```

业务模块只依赖统一领域接口，不直接调用第三方数据 SDK 或 SQLite SQL。SQLite 规划为权威事实与审计库；未来存储扩展必须保持相同的时间可见性、版本选择和血缘语义。策略只产生交易意图，执行模拟器决定成交，组合记账只根据成交改变现金与持仓。

## 环境与平台职责

| 环境 | 规划职责 | 边界及当前状态 |
| --- | --- | --- |
| 本地 PC | 数据采集、清洗、归档、SQLite、指标、研究、回测、日报构建及人工审阅；后续本地定时任务 | 受保护配置保留在本地；已有数据库初始化入口，其余运行工具待实现，P0 不使用交易凭据 |
| Codex Cloud | 在隔离开发环境中辅助修改代码、审查契约、运行合成数据测试和准备 PR | 开发协作角色；非生产采集或回测运行平台，不依赖本地数据库和生产密钥；尚未配置环境 |
| GitHub | 代码与文档版本管理、分支、PR 审查及后续 CI | 已连接 fengjnah/a-share-quant-v1；默认 main；不存储私密配置、原始数据、SQLite 或运行产物；CI 待实现 |
| AWS EC2 t3.micro | Nginx 只读托管本地已构建、审核的静态 HTML/JSON、资源和 manifest | 尚未部署；不保存全量历史库或数据源/交易凭据，不采集、不计算、不回测、不连接交易账户 |

Codex Cloud 与 GitHub 的协作分工是本文补充的开发流程建议；计算及 AWS 运行边界来自已采纳的 ADR-003。

